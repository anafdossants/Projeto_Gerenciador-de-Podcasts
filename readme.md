<h1>Podcast</h1>

O Podcast Manager é uma API inspirada no estilo Netflix que organiza episódios de podcasts por categorias, facilitando a navegação e descoberta de conteúdos em formato de vídeo.
</div>
<br>

<h2>🟪Funcionalidades</h2>
- Listagem de episódios organizados por categorias (saúde, esporte, mentalidade, humor etc.)<br>
- Filtro de episódios por nome do podcast<br>
- Exibição de informações como título, vídeo, capa, link e categorias<br>
- GET /list → Retorna todos os episódios organizados por categorias<br>
- GET /episode?podcastName={nome} → Retorna episódios filtrados pelo nome do podcast<br>


<h2>🟪Tecnologias</h2>
-Node.js<br>
-TypeScript<br>
-tsx<br>
-tsup<br>
-@types/node<br>
